1

가게 등록하기

가게 사장님 폰약 10분

이걸 먼저 해야 2페이지에서 볼 게 생깁니다. 순서대로 하세요.

1

업체 소개에서 신청 시작

조작하단 메뉴 → 업체 소개 화면에서 [신청하기]

결과신청서 화면으로 넘어간다

됨안 됨
2

신청서 작성 + 위치 찍기

조작상호명·업종·연락처·주소를 채우고 지도에서 현재 위치를 찍은 뒤 제출

결과핀이 지금 서 있는 자리에 정확히 찍힌다. 사진은 없어도 제출된다. 제출하면 "심사중" 화면

심사중 상태에서 가게 관리 화면에 들어가면 다시 "심사중"으로 튕겨야 정상

됨안 됨
3

승인 후 — 파트너 라운지

조작노트북 관리자 화면에서 승인한 뒤, 다시 폰에서 가게 관리 진입

결과신청할 때 넣은 정보 그대로. 카메라 버튼으로 사진을 바꾸면 바로 반영되고, 앱을 껐다 켜도 유지

됨안 됨
4

가격표 등록

조작라운지에서 [가격표] → 메뉴와 가격을 3~4개 등록. 하나는 삭제도 해보기

결과추가·삭제 모두 즉시 반영

수정 버튼은 원래 없습니다 — 지우고 다시 넣는 게 정상

됨안 됨
중간에 노트북에서 관리자 승인이 한 번 필요합니다 (관리자 화면 → 업체 계정 목록 → 승인). 한 건은 일부러 반려해서, 폰에 반려 사유가 뜨고 [재신청]을 누르면 쓴 내용이 그대로 채워지는지도 보세요.

2

손님 눈으로 확인하기

손님 폰 (다른 사람 폰)약 5분

1페이지에서 사장님이 만든 게 손님 화면에 그대로 보이는지가 전부입니다.

5

동네지도에 가게가 뜬다

조작하단 동네지도 열기

결과가게 카드가 보이고 이름 옆에 동 이름 칩(Sài Gòn 등)이 붙어 있다. 거리·후기·단골 수도 함께

됨안 됨
6

가게 상세 — 사진과 지도

조작가게 카드를 눌러 상세로 들어가기

결과사장님이 올린 사진이 보이고, 연락처/주소 카드 바로 아래 지도 카드, 그 아래 소식 순서

여기서 [단골 맺기]를 눌러두면 내 프로필 → 단골 업체에 뜹니다

됨안 됨
7

가격표가 손님에게 그대로

조작상세 화면 위쪽 [가격] 탭

결과1페이지에서 사장님이 넣은 항목·금액이 똑같이 나온다

됨안 됨
8

침수 지도

조작정보 → 침수 지도. 지도를 손가락으로 옮기고 확대해 보기

결과아래 목록이 보이는 범위에 맞춰 바뀐다

지도 위 집계 배지는 눌러도 반응이 없는 게 정상 (개별 마커만 눌림)

됨안 됨
홈 화면의 업체소식은 옆으로 넘기는 가로 띠, 커뮤니티 피드는 2열 격자로 보이면 정상입니다. 단골 맺은 가게가 소식을 올려도 알림은 오지 않습니다 — 아직 안 만든 기능이라 버그가 아닙니다.

3

중고거래 — 올리고 찾기

파는 사람 폰 + 사는 사람 폰약 8분

이 서비스엔 결제가 없습니다. 채팅으로 약속 잡고 만나서 직거래하는 흐름입니다.

9

번호 인증부터 막힌다 (정상)

조작인증 안 한 상태로 중고거래 글쓰기를 눌러보기

결과글쓰기가 안 열리고 번호 인증 화면으로 넘어간다

개발 서버라 문자는 안 옵니다. 아무 번호 + 아무 6자리면 통과 (화면에도 안내가 떠 있음)

됨안 됨
10

물건 올리기

조작제목 + 폰카로 찍은 사진 + 지역을 넣고 등록. 가격은 비워보기

결과사진이 한 장도 없으면 등록 버튼이 안 눌린다. 가격을 비우면 "나눔"으로 표시된다

하나 더 올릴 땐 가격을 넣고 "가격 제안 받기"를 켜두세요 — 4페이지에서 씁니다

됨안 됨
11

사는 사람 폰에서 찾기

조작다른 폰으로 중고거래 목록 열고 아래로 계속 스크롤

결과방금 올린 물건이 위쪽에 있고, 스크롤하면 계속 더 불러온다

위치 모드(전체 / 내 위치 / 지도선택)를 바꾸면 실제 서 있는 위치 기준으로 목록이 달라집니다

됨안 됨
12

검색과 필터

조작검색창에 제목 일부 입력 → 카테고리·가격대 필터·정렬 바꿔보기

결과0.3초쯤 뒤 결과가 뜨고, 조건에 맞는 것만 남는다

검색 화면 정렬은 최신순·낮은가격·높은가격 3개뿐 — 거리순은 메인 목록에만 있습니다

됨안 됨
찜(하트)은 해제가 상세 화면 하트에서만 됩니다. 찜 목록에 보이는 하트는 개수 표시용이라 눌러도 안 풀립니다 — 정상입니다.

4

거래 성사시키기

두 폰을 번갈아 가며약 10분

채팅 → 가격흥정 → 약속 → 직거래 → 후기. 앱의 핵심 흐름입니다.

13

사는 사람이 말 걸기

조작물건 상세에서 [채팅하기]

결과그 물건이 위에 붙은 채팅방이 열리고, 파는 사람 폰에 안 읽음 배지가 뜬다

됨안 됨
14

가격제안 + 약속 — 파는 사람 화면

조작사는 사람이 [가격제안] 금액 입력 → 파는 사람이 [수락] → 아무나 약속(장소·시간) 잡기

결과양쪽 채팅에 카드가 똑같이 뜬다. 약속 수락 버튼은 제안한 사람 반대편 폰에만 보인다

됨안 됨
15

채팅 목록

조작하단 채팅 탭

결과대화가 구분되고 안 읽은 건 배지가 붙는다

약속을 수락하면 물건이 자동으로 "예약중"으로 바뀝니다

됨안 됨
16

거래완료 → 후기 → 이력

조작파는 사람이 약속 카드에서 [거래완료] → 양쪽이 서로 후기(별점) 작성 → 거래 이력 확인

결과물건이 자동으로 판매완료. 이력에 판매/구매가 구분돼 보인다

"판매완료"로 직접 못 바꿉니다 — 약속 완료를 눌러야 자동으로 바뀌는 게 정상

됨안 됨
후기를 쓰면 상대 프로필의 신뢰 등급 칩이 바뀔 수 있습니다. 매너온도 숫자는 원래 화면에 안 나옵니다 — 등급만 나옵니다.

버그가 아닌 것 & 문제 적는 칸

마지막에 한 번

아래 8가지는 아직 안 만든 기능입니다. 테스트 중 만나도 문제로 적지 마세요.

  1. 단골 가게가 소식을 올려도 알림이 안 옵니다 (단골 목록을 직접 열어야 보임)
  2. 가격표 항목 수정 불가 — 삭제 후 재등록
  3. 침수 지도의 집계 배지는 눌러도 반응 없음 (개별 마커만 눌림)
  4. 업체 대시보드에 단골 손님 명단 화면 없음 (숫자만 나옴)
  5. 광고는 지금 꺼져 있어서 앱 어디에도 광고가 안 보임 (대시보드 통계는 별개로 정상)
  6. 물건 상태를 손으로 "판매완료"로 못 바꿈 — 약속 완료를 눌러야 자동 전환
  7. 매너온도 숫자는 화면에 안 나옴 — 등급 칩만
  8. 인증 문자가 실제로 오지 않음 — 아무 6자리나 통과 (개발 서버 설정)
