# 당근 동네지도 조사 — 사이공라이더 동네지도 개편 방향 제안서

> 상태: **완료 (2026-07-10)** · Plane **SGR-315** · 원장 [`_HANDOFF.md`](_HANDOFF.md) · 원문 [`sources/`](sources/) (공식 10 + 실기기 스크린샷 3 + 외부 6 + 내부 1)
> 출처 표기: OF-n(당근 공식) / EX-n(외부 기사·가이드) / IN-n(지시자 제공 실기기 스크린샷) / INT(내부 스냅샷) — 식별자↔파일 매핑은 `_HANDOFF.md` 수집 표.

## 0. 결론 요약

당근 동네지도의 본질은 "지도 앱"이 아니라 **③번 탭까지 승격된 로컬 비즈니스 발견면(discovery surface)** 이다. 성공 공식은 세 가지로 압축된다:

1. **공급(장소 데이터)은 UGC + 비즈프로필 이중 트랙으로 채운다** — 지역인증 유저의 장소 등록·후기 + 사업자의 비즈프로필 등록(주소 유효 → 지도 자동 반영). 콜드스타트는 리워드 캠페인과 커뮤니티 게시글 LLM 태깅으로 돌파했다.
2. **지도는 참여 루프의 무대다** — 후기·단골·쿠폰·소식이 핀과 카드로 지도 표면까지 올라온다. 지도 = 읽기 전용 뷰가 아니라 참여의 진입점.
3. **수익화는 그 위에 얹는다** — 등록 무료·노출 유료(비즈프로필 광고, CPC, 2026년 동네지도 검색광고 시범). 단 "광고비 안 내면 노출 급감" 비판(EX-4)이 따라붙는 구조라는 것도 확인됨.

**사이공라이더에의 함의(한 문장)**: 우리 동네지도는 현재 "중고 매물 지도"에 머물러 있고, SGR-312로 만든 비즈프로필·광고 인프라가 지도와 미연결 상태다(INT §7). **개편의 1순위는 신규 기능 발명이 아니라, 이미 있는 비즈프로필을 지도 핀 레이어로 올리고 후기·RP 리워드 루프를 붙이는 것** — 당근이 검증한 공식을 기존 인프라 재사용으로 달성할 수 있다. 상세 판단은 §6.

## 1. 정보구조(IA) — 진입점·화면 구성 (Q1)

**탭 위상**: 동네지도는 하단 5탭 중 **정중앙 3번째 탭** (홈/커뮤니티/**동네지도**/채팅/나의당근) — IN-1 실기기 확인, OF-2·OF-3 공식 문구("당근 앱의 세 번째 탭")와 일치. 중고거래 앱의 한가운데에 지도를 놓을 만큼 전략적 위상이 높다. 로컬맵스팀 인터뷰(OF-1)에 따르면 이 개편은 "기획부터 배포까지 1년", 전사 합의("당근이 로컬 서비스를 한다면 지도는 반드시 있어야 한다") 하에 자체 지도 플랫폼까지 구축한 프로젝트다.

**첫 화면 = 풀스크린 지도** (리스트 아님, IN-1):
- 상단: 검색바 — placeholder **"집 근처 업체 검색"** (검색의 목적어가 '장소'가 아니라 '업체'). 우측 프로필 아바타.
- 검색바 아래 가로 스크롤 **카테고리 칩**: `포장주문` `할인중` `음식점` `용달` … — 업종 축(음식점)·혜택 축(할인중)·행동 축(포장주문)·서비스 축(용달)이 **혼재**. 순수 업종 분류가 아니라 "지금 뭘 하고 싶은가" 중심.
- 좌측 플로팅 스택: 동네걷기(혜택 미션, OF-6) / 하트(장소 저장 — 2022년 도입, OF-4) / 장소 등록 / 현위치.
- 우하단: "내 장소" 버튼 + 주황 대형 `+` FAB.
- 하단: 접힌 콘텐츠 카드(추천 콘텐츠 바텀시트).

**연혁** (교차검증): 2021-05 '오픈맵' 시작(EX-1·EX-2) → 2021-11 '우리동네맛집지도' 정식 오픈(EX-3·OF-4) → 2022-03 '당근지도' 개칭, 2022-07 6개 카테고리(음식점·카페/디저트·병원/약국·미용/뷰티·운동·반려동물) 확대 + 장소 저장(OF-4) → 2024~2025 3번째 탭 '동네지도'로 개편·전국 오픈(OF-1·OF-2).

## 2. 지도 위 콘텐츠 — 핀 노출·상호작용 (Q2)

IN-1/IN-2 실기기 관찰 기준:
- **업체 핀** = 주황 원형 + 업종 아이콘 + 핀 아래 상호명 텍스트 라벨. 도시 일부 스팬 줌에서도 라벨 핀 5~6개만 **선별 노출** — 과밀하지 않다. (선별 기준은 공식·외부 어디서도 원문 미확보 — §7 잔여 갭. 대행사발 "단골/후기가 노출에 영향" 추정만 존재해 미채택.)
- **소식 결합**: 새 소식 있는 업체 핀에 빨간 점 + 지도 위에 소식 첫 줄 **말풍선 프리뷰**가 직접 노출("새소식 1일 전 — …"). 업체가 글을 쓰면 지도가 살아 움직이는 구조.
- **선택 상호작용**: 핀 탭 → 대형 물방울 핀 강조 + 하단 **가로 스와이프 카드 캐러셀**(업체 소식 카드 — 아바타·상호·"3시간 전"·본문). X로 해제.
- **소셜 프루프**: 선택 시 "👁 10명이 보는중" 실시간 열람자 칩(IN-2).
- **비업체 POI**(마사지·역·산 등)는 다른 시각 언어(파랑·회색 계열)로 병행 노출 — 업체 레이어와 구분.
- **장소 상세**(핀→프로필 진입 시): "메뉴판과 가격, 동네주민 후기, 가게 관련 동네생활 이야기"(EX-2, 2021 출시 기사). 별점 언급은 전 출처에서 없음 — 후기 텍스트 중심으로 보이나 **별점 부재를 단정할 원문은 미확보**(§7).
- 배경 지도는 **자체 제작**(워터마크 없음) — "동네 사람들이 보는 지도"는 편의점·아파트 단지 녹지 같은 마이크로 랜드마크가 잘 보여야 해서 범용 지도로는 불가능했다는 게 공식 설명(OF-1, Heart/Jane).

## 3. 데이터 소싱 — 공급 확보·콜드스타트 (Q3)

당근의 장소 데이터는 **이중 트랙**:

**① 유저 트랙 (UGC 오픈맵)** — 지역 인증 유저 누구나:
- 장소 등록 제안 ("장소 등록 제안하기" 버튼, OF-2) / 장소 추천 게시글 작성(OF-4).
- **동네생활(커뮤니티) 게시글 → LLM 자동 장소 태깅 → 지도 반영** (OF-1·OF-9): "수선집 추천해주세요" 글의 댓글 추천을 LLM이 장소로 연결해 휘발을 막음. "이웃들이 자연스럽게 대화하는 것만으로 기술이 정보를 찾아 지도로 옮겨준다."
- 후기 품질도 LLM으로 평가해 **신뢰할 수 있는 정보일수록 높은 보상**(OF-1, Neil).

**② 사업자 트랙 (비즈프로필)** — 업종 선택 = 동네지도 노출 카테고리 결정, **"입력한 주소가 유효한 경우 동네지도에도 반영"**, 주소 없으면 활동지역 기반 노출(OF-8). 등록은 무료(EX-1).

**콜드스타트 돌파 장치** (효과 수치는 공식 발표치):
- '당근 모으기' 리워드 캠페인 → **제안 장소 정보 90% 증가**(OF-1).
- '동네 가이드 점수'(기여 점수) → **하루 후기 10개+ 열성 유저 10배 증가**(OF-1).
- 동네지도 챌린지(2024): 후기 작성 시 랜덤 당근머니 즉시 적립, 사진 첨부·상세 작성일수록 리워드 증가(OF-2).
- 원형(origin): 2020년 유저 자발 '붕어빵 지도'가 성공 확신의 근거(OF-1).
- 시즌 테마지도(겨울 간식·친환경, OF-4)와 후기 데이터 기반 랭킹 콘텐츠(빵집 TOP100 OF-3, 맛집 밀집지역 랭킹 EX-3)를 마케팅 소재로 재활용 — 데이터가 다시 참여를 부른다.

## 4. 참여 루프 — 후기·단골·소식·쿠폰 (Q4)

지도에 붙어 있는 리텐션 장치 전부:

| 장치 | 내용 | 근거 |
|---|---|---|
| 후기 | 업체 프로필 '후기' 탭에서 작성, 리워드 연동(챌린지), LLM 품질 평가 | OF-2, OF-1 |
| 단골 맺기 | 업체당 누적 카운트("100번째 단골맺기") — 소식으로 자랑되는 사회적 자산 | IN-2 실물 |
| 쿠폰 | 비즈프로필 발급, 단골 등록+참여권 발급 → 매장 방문 수령 흐름 (온라인→오프라인) | OF-3, IN-2 |
| 소식 | 업체 게시글이 지도 핀 뱃지·말풍선·하단 카드로 노출 | IN-1/IN-2 |
| 장소 저장 | 하트 저장 → 책갈피 목록(목록/지도 보기), '나의당근'에서도 접근 | OF-4 |
| 동네걷기 | 걸음수+GPS 보물상자, 일 최대 200원 당근머니, 가게 방문+후기 시 추가 혜택 — 동네지도 탭 내 '혜택 미션' | OF-6, EX-5 |
| 참여형 미니콘텐츠 | 동네 가게 퀴즈, 가본 곳 찍기, "우리집 중심 500m 딱 맞추기" | OF-6 |

핵심 패턴: **모든 참여 장치가 결국 '가게 방문/후기'로 수렴**한다. 걷기 보상도 가게 근처 보물상자 + 방문 후기 추가 혜택으로 설계됨 — 리워드가 트래픽이 아니라 **로컬 상권 데이터 생산**에 지급된다.

## 5. 수익화 — 비즈프로필·광고 결합 (Q5)

- 기본 공식: **등록 무료, 노출 유료** (2021 출시 시점부터, EX-1).
- 광고 집행: '나의 당근' → 광고 메뉴, 비즈프로필 = 랜딩 페이지, **CPC 과금**, 노출 위치를 **홈 피드 / 검색 결과** 중 선택, 동네 단위 타기팅(EX-6). 2023년 반경 타기팅(300m~1.5km) 출시(OF-5).
- **최신(2026-04): 동네지도 검색 결과 상단에 검색광고(텍스트/이미지) 시범 운영**(EX-5) — 지도 검색면 자체가 광고 슬롯이 되는 단계로 진화 중.
- 그림자: "광고비를 주기적으로 내지 않으면 기존 단골도 경쟁 업체에 빼앗길 수 있다", "광고 피라미드 구조" 비판(EX-4, 2025). 전문성 검증 없는 광고 등록 가능성 지적도. 수익화 강도가 신뢰 자산을 갉아먹는 긴장이 실재.
- 사업 성과(전사): 2026 2Q 영업이익 185억(+176.5%), 매출 645억(+51%)(EX-4) — 하이퍼로컬 광고 모델의 규모 증명.

## 6. 사이공라이더 갭 분석 — 채택 / 변형 / 배제 (Q6)

**현행 요약**(INT): `/map` 동네지도는 **매물(주황)·피드(파랑) 핀 2종**만 표시. 줌 게이트(2026-07-07)·GPS 4컨텍스트·뷰포트 복원은 안정화 완료. **SGR-312 비즈프로필·광고 인프라(business_profile APPROVED 게이트, marketplace_ads, `/biz/:id` 공개 프로필)는 지도와 미연결** — 유일한 접점은 리스트 4건마다 끼는 AdCard(→`adHref()`→`/biz/:id`). info 계열(주유·정비·침수)은 별도 지도(SaigonDistrictMap)로 완전 분리.

## 7. 잔여 갭 (확인 불가 — 정직 표기)

- **핀 노출 선별 알고리즘**: 공식 FAQ(cs.kr.karrotmarket.com)가 SPA라 원문 미확보. 재시도하려면 브라우저 기반 도구 필요.
- **장소 상세의 별점 유무·버튼 구성(채팅/전화)**: "메뉴판·가격·후기·동네생활 이야기"(EX-2)까지만 원문 확보. 별점 부재는 정황상 유력하나 미단정.
- **동네지도 자체 정량치**: 부분치만(이용자 3배 2022, 제안 장소 90%↑·열성유저 10배 2025, 방문 가게 33만 2025). 총 이용자·등록 업체 수 미공개.
- 필요 시 실기기 추가 캡처(장소 상세·검색 결과 화면)가 가장 확실한 보완 수단 — IN-1/IN-2와 같은 방식.
