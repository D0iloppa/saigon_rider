# 사이공라이더 출시 전 부족사항 정리

작성일 2026-08-09

## 요약 (먼저 읽을 것)

**결론: 앱 기능 개발은 끝났다. 남은 건 ① 스토어 제출용 앱 식별정보 교정 ② 운영서버 실가동 준비 ③ 실기기 검증 ④ 법무·계약 회신 — 이 네 덩어리다.**

**지금 당장 손대야 하는 것 (제출 자체가 막히거나 반려되는 것)**

| # | 항목 | 상태 |
|---|---|---|
| 1 | AdMob App ID가 **구글 샘플 테스트 ID** — Android·iOS 둘 다 | 실측 확인 |
| 2 | iOS Bundle ID가 안드로이드와 **다름** (`com.user.SaigonRiders` vs `com.saigonrider.user`) | 실측 확인 |
| 3 | iOS 권한 요청 문구가 **전부 한국어** (베트남 서비스인데) | 실측 확인 |
| 4 | iOS **상시(Always)/백그라운드 위치 권한**이 박혀 있는데 실사용처 없음 → Apple 소명 요구 대상 | 실측 확인 |
| 5 | 서명 팀 ID 2종 혼재 (`52G63UPLD9` / `3QRB73494R`) | 실측 확인 |

**출시는 되지만 사용자가 못 쓰는 것**

| # | 항목 | 영향 |
|---|---|---|
| 6 | 운영 `SMS_PROVIDER_API_KEY` 미설정 | **가입·판매 전면 502** — 신규 가입 0명 |
| 7 | 강제 업데이트 안전망 미작동 (`appVersion: 'unknown'`) | 출시 후 **긴급 패치를 강제할 수단이 없음** |
| 8 | Zalo 앱 `Chưa kích hoạt`(미활성) | 현지 주력 로그인 수단 불가 |
| 9 | 등록 업체가 전부 dev 시드 (승인 7건) | 첫 사용자가 빈 앱을 봄 |
| 10 | 운영서버 최신화 안 됨 + 운영 DB 마이그레이션 미적용 | 최신 코드가 운영에 없음 |
| 11 | 백업·복구·장애경보 전건 미검증 | 사고 시 복구 불가 |

**대표 결정이 필요한 것 (개발이 아니라 판단 대기)**

- 업체 광고(`ADS_ENABLED=false`)를 출시 시점에 켤 것인가 — 현재 전면 OFF, 개발서버 한정
- 근접 광고(가게 접근 알림)는 **아직 착수 자체가 안 됐다** — 출시 범위에 넣을지
- 쿠폰 교환 카탈로그 OFF 유지 여부 (실제 fulfillment 파트너 미확정 — NDA 회신 대기 중)
- 마일리지 오염 데이터 약 12,096km 정정·회수 범위
- 서비스 지역을 도심 37개 동으로 한정한 채 출시할지

**대표 보고 시 프레이밍 권고** — "출시준비 완료"라고 이미 답했으므로, **"앱 기능 = 완료 / 스토어 제출정보·운영환경·실기기 검증 = 잔여"** 로 완료의 정의를 나눠서 말하는 게 정확하고 모순도 없다.

## 0. 사용자가 이미 파악한 4건 — 실제 범위

| 파악한 내용 | 실제 확인된 범위 |
|---|---|
| 운영서버 최신화 안 됨 | 맞음. + **운영 DB에 마이그레이션(172) 미적용**, push 안 한 커밋 다수(라우팅 엔진 6건 포함, 첫 push는 타일 때문에 136MB) |
| 휴대폰 인증 베트남 번호 테스트 필요 | 맞음. 다만 더 앞선 문제 — **운영에 SMS API 키가 아예 안 들어가 있으면 가입이 502로 전면 차단**된다. 또 SpeedSMS 발신자 브랜드네임 승인 여부는 계약 문제라 코드로 확인 불가 |
| 업체 광고가 개발서버 한정 | 맞음. + 게이트가 **2중**이다 — `ADS_ENABLED=false` 상수와 `isDev` 런타임 플래그. 켤 때 하나만 풀고 잊을 위험 |
| 가게 인접 광고알림 검증 필요 | **검증이 아니라 미착수**다. 설계서(`260806_proximity_ad_design.md`) §9의 백엔드·프론트 진입감지 1~7번이 전부 착수 전. 선행조건은 유료 가맹점 확보 |

## 1. 스토어 제출 차단 요소 (앱 식별정보)

전부 오늘 직접 파일에서 확인한 값이다.

1. **AdMob 샘플 App ID 사용**
   - `native/android/app/src/main/AndroidManifest.xml:42` → `ca-app-pub-3940256099942544~3347511713`
   - `native/ios/SaigonRider--iOS--Info.plist:8` → `ca-app-pub-3940256099942544~1458002511`
   - `3940256099942544`는 구글이 공식 문서에 공개한 **테스트 계정 번호**다. 이대로면 수익이 0이고 정책 위반 소지가 있다. 실 계정 ID로 교체 필요.

2. **iOS Bundle ID 불일치**
   - `native/ios/SaigonRider.xcodeproj/project.pbxproj:490,535` → `com.user.SaigonRiders`
   - Android(`native/android/app/build.gradle:11`)와 Capacitor 설정은 `com.saigonrider.user`
   - App Store Connect에 등록한 앱 레코드의 Bundle ID와 다르면 **업로드 자체가 실패**한다. 어느 쪽이 정본인지 확정 필요.

3. **iOS 권한 문구 한국어** (`project.pbxproj:473-478`, `518-521`)
   - 예: `NSLocationAlwaysAndWhenInUseUsageDescription = "위치 추적을 위해 필요합니다"`
   - 베트남 사용자가 한국어 팝업을 본다. 최소 영어, 권장은 베트남어.

4. **상시/백그라운드 위치 권한이 실사용처 없이 선언됨**
   - iOS: `NSLocationAlways…` + `UIBackgroundModes: location`
   - Android: `ACCESS_BACKGROUND_LOCATION`
   - 그런데 근접광고 설계서는 **"백그라운드 위치 추적 미도입 확정(포그라운드 전용)"** 이라고 명시했고 관련 기능도 미착수다. Apple은 상시 위치에 대해 소명을 요구하며, 근거가 없으면 반려 사유가 된다. → 내비 화면잠금 대응 등 실제 용도가 없다면 **권한을 빼는 게 안전**하다.

5. **서명 팀 ID 2종 혼재** — `project.pbxproj:378,440`(`52G63UPLD9`) vs `469,514`(`3QRB73494R`). 배포 빌드가 의도한 팀으로 서명되는지 확인.

6. **잔재 파일** — `native/ios/Letanton--iOS--Info.plist` (다른 앱 이름). 빌드 참조 여부 확인 후 제거.

7. **Zalo OAuth 앱 미활성** (`Chưa kích hoạt`) — 활성화 전까지 실사용자 로그인 검증 자체가 불가능. 베트남 주력 로그인 수단이라 사실상 차단 요소.

## 2. 운영환경 준비 (출시하면 바로 터지는 것)

1. **운영 SMS 키 미설정 시 가입 전면 차단** — 코드는 fail-safe로 설계돼 있어(키 없으면 인증코드를 로그로 흘리지 않고 502로 실패) 보안은 옳지만, 운영에 키가 없으면 **가입·판매 등록이 전부 502**다. 출시 전 필수 확인 1순위.
2. **운영서버 최신화 + DB 마이그레이션** — 172(행정구역 명칭 교정)가 dev에만 적용됨. 운영은 수동 실행 필요.
3. **미push 커밋 정리** — 자체 라우팅 엔진(Valhalla) 6커밋 등이 로컬에만 있음. 첫 push는 타일 데이터 때문에 약 136MB.
4. **임시조치 미커밋 상태** — Google 길찾기 폴백을 검증 목적으로 꺼둔 변경이 워킹트리에만 있다. 다른 세션이 `git add -A` 하면 딸려 들어간다. 출시 전 **폴백을 되살릴지 여부 결정 + 정식 커밋** 필요.
5. **백업·복구·경보 전건 미검증** — 백업 실행 증적 없음, 복구 훈련(RPO/RTO) 미실측, 5xx 경보 실제 발화 미확인, 온콜·롤백 책임자 미지정.
6. **Engine 서비스 키 회전 미완** — 신규 앱 배포 전 `ENGINE_SERVICE_KEY` 회전 및 모바일 패키지 identity 분리.
7. **Zalo 인증 프록시 VPS가 단일 장애점** — 이게 죽으면 Zalo 로그인 전면 불가. 업타임 모니터링 없음.
8. **실제 업체 데이터 부재** — 승인된 업체 7건이 전부 dev 시드. 출시 시점에 실제 가맹점이 없으면 앱이 비어 보인다. (영업 트랙 이슈)

## 3. 실기기 검증 미완 (전건)

서명 빌드 + 실기기가 있어야만 가능한 항목들이고, 현재 진행현황표상 전부 미완이다.

- GPS 권한 허용/거부/백그라운드 동작
- FCM 푸시 토큰 등록·회전, 푸시 딥링크 진입
- OAuth 3종(Google / Apple / Zalo) 성공·취소·오류 경로
- **강제 업데이트** — `@capacitor/app`이 네이티브에 sync 안 돼 `appVersion: 'unknown'`. 즉 **현재 강제 업데이트가 절대 발동하지 않는다.** 출시 후 치명적 버그가 나와도 구버전 사용자를 밀어올릴 수단이 없으므로, 개인적으로는 이게 실기기 항목 중 가장 위험하다고 본다.
- 오프라인 상태 동작
- 구형 Android WebView safe-area 표시
- 베트남 현지 번호 SMS 수신 실측
- 길찾기 실기기 종단 검증 (자체 라우팅 엔진 전환 후 미검증)

## 4. 법무·계약

- **개인정보처리방침 법무 최종 승인 미접수** — 초안 표식은 제거·배포됐으나 외부 자문 회신은 아직. 내부적으로 §5(이용자 권리)와 §4(보유·파기) 문구가 서로 어긋난 채 남아 있음.
- **위치정보 조항** — 현재 앱이 요구하는 권한(특히 iOS 상시 위치)에 대한 법적 근거 문구가 방침에 반영됐는지 미확인. §1-4번과 같이 봐야 함.
- **쿠폰업체 NDA 회신 대기** — 이게 안 오면 쿠폰 교환 카탈로그는 계속 OFF 유지.
- **passcode 평문 쿠키 → HttpOnly + JWT 전환 미완** — 문서상 "정식 출시 전 교체 필요"로 명시된 보안 항목인데 현재 상태 유지 중.

## 6. 대표 결정 대기 (개발 아님)

1. **마일리지 오염 데이터** — 거리 검증 게이트 결함은 수정·커밋 완료. 다만 이미 쌓인 오염분 약 **12,096km(8개 기기 411행, 최대 1개 기기 6,682km)** 를 정정할지, 지급된 보상을 회수할지 미결.
2. 누적 주행거리 UI 표시를 유지할지 (위치 핀 아이콘 옆에 있어 "현재 거리"로 오인됨)
3. 탈퇴 후 동일 OAuth 재로그인 시 주행거리 승계 — 개인정보 관점 검토 필요
4. 홈 구조: 현 홈 유지 vs 마켓 4탭 구조
5. 게임 재화·퀘스트 은폐 범위 최종 확정
6. 약관 문안·고객 연락수단·콜드스타트 문구

## 8. 잘 돼 있는 것 (보고 시 근거로 쓸 것)

- **DEV 우회 차단이 견고함** — OTP 개발 우회·dev 로그인 모두 운영 compose에서 `APP_ENV=production`, 우회 키 공란으로 하드 고정. 미설정 시 dev로 판정되지 않는 fail-closed 구조이고 전용 테스트도 있음.

- **CI 구성 완비** — backend·engine pytest, 프론트 타입체크·린트, PR 시 Playwright E2E.

- 마일리지 거리 검증 게이트 결함은 이미 수정·독립 리뷰 통과.

## 9. 내일 미팅에서 나올 질문과 답변 준비

1. **"언제 출시 가능?"** → §1(반나절~1일, 코드 교정) + §2(운영 세팅, 1일) + §3(실기기 검증, 1~2일) + §4(법무·NDA 회신, **외부 의존이라 통제 불가**). 외부 회신을 뺀 내부 작업만으로는 3~4일 규모.
2. **"완료했다며?"** → 앱 기능은 완료. 남은 건 제출용 식별정보·운영환경·실기기 검증·법무 회신.
3. **"줍고 안드로이드랑 같은 주에 되나?"** → 리소스 배분 답변 준비 필요. 줍고는 프로덕션 신청(제출 행위), 사이공은 위 4덩어리로 성격이 다름.
4. **"뭐가 제일 위험해?"** → 강제 업데이트 미작동. 출시 후 문제가 생겨도 구버전을 밀어올릴 수단이 없다.
