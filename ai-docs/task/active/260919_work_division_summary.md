## 2. 판정해 주실 것 — 서비스 플로우 시트

이 흐름과 제안은 제가 정의한 것이고, 구현 전에 판정을 받습니다. 판정은 **승인 / 수정(어떻게) / 보류** 셋 중 하나입니다.

| 단계 | 사용자 목표 | 지금 문제 | 제안 | 판정 |
|---|---|---|---|---|
| S0 출품 | 오토바이·용품을 올린다 | 비가역인 "매물 철회"가 끌어올리기·가격수정과 같은 줄·같은 모양 | 철회를 위험 톤으로 분리, 확인 문구 유지 | ☐ |
| S1 발견 | 매물을 찾고 찜한다 | 찜 목록에서 하트가 표시 전용이라 해제 불가 | 하트 토글로 해제 가능 | ☐ |
| S2 문의 | 판매자에게 묻는다 | DM 상단 아이콘 4개가 같은 무게. 그중 무전기는 누르면 상대에게 즉시 초대가 감 | 무전기는 필요 시점에만 노출, 상단은 뒤로·프로필·더보기 3개 | ☐ |
| **S2-무전기** | 통화처럼 바로 말한다 | **지난 채팅방 지적** — 진입 시점·종료 방식이 정해진 기준 없음, 화면 위를 떠다니고 손으로 끌림 | 대표님이 사용자라면 어디서 열고 어떻게 닫을지 정해 주시면 그대로 구현. 채팅방 입력창 위 **하단 고정 바**로 통합(드래그 제거) | ☐ |
| S3 합의 | 만날 시간·장소를 정한다 | 약속 잡기가 "+" 메뉴 안에 이모티콘과 나란히 있어 시야 밖 | 매물 카드에 "약속 잡기" 칩으로 승격 | ☐ |
| S4 이동 | 약속 장소로 간다 | 상대가 취소해도 푸시 없음, 취소에 확인 없음 | 취소 푸시 추가, 취소 전 확인 1회 | ☐ |
| S5 대면 확인 | 물건을 직접 본다 | 안전거래 가이드에 대면 수칙이 없음 | 가이드에 대면 수칙 섹션 추가 | ☐ |
| **S6 결제** | 확인한 값을 낸다 | 타임라인이 "송금 → 수령 확인" 순으로 결제가 확인보다 앞. **만남 전 송금이 가능** | 결정 1에 따라 약속 시각 창 안에서만 송금 허용, 순서를 "확인 → 결제 → 완료"로 재배열 | ☐ |
| S7 완료 | 거래를 끝내고 평가한다 | 거래 이력 탭이 대화가 아니라 매물로 이동. 완료 처리에 확인 없음 | 이력 → 대화방으로, 완료 전 확인 1회 | ☐ |
| X 종료 | 취소·신고·차단 | 더보기 메뉴에 [신고][위치 공유][나가기]가 섞여 신고하려다 위치 공유 초대가 나갈 수 있음 | 더보기는 [신고][나가기]만 | ☐ |
| N 떠 있는 것 | 진행 중 도구를 예측 가능한 자리에서 쓴다 | **지난 채팅방 지적** — 무전기·위치공유 버튼 둘 다 화면 위를 떠다니고 서로 겹침 | 둘을 하단 고정 바 하나로 통합 | ☐ |

지난번 채팅방에서 지적하신 세 가지(① 신고·위치공유·나가기 같은 레벨 ② 무전기가 떠다님 ③ 위치공유 버튼도 떠다님)는 위 표의 S2 문의·S2-무전기·N 떠 있는 것 줄이 각각 답합니다.

**참고**: 이번 승인은 정책 방향에 대한 것입니다. S6 결제·X 종료(취소·교착·신고·차단) 관련 화면 6개는 스토리보드에 아직 요소 표가 없어 화면 자체가 정의되지 않았고, 실제 구현 전 그 화면들을 별도로 정의해 다시 판정받습니다.

**11줄 중 반드시 회신을 기다리는 건 S2-무전기·S6 결제 2줄뿐입니다**(과거 이견이 있었던 지점). 나머지 9줄은 대표님이 이미 채팅방에서 말씀하신 원칙(같은 메뉴엔 같은 성격만 / 진행 중 도구는 고정 위치)에서 그대로 나오는 결함 수정이라, **화요일 자정까지 회신이 없으면 표대로 진행**하고 반영 내역을 수요일 보고에 적습니다.
