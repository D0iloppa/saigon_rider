# 관리자 콘솔 화면 리빌드

## 목적

신규 `/admin` React SPA의 API·라우트·업무 기능은 보존하고, 기본 Ant Design 화면 조합 수준의 표면을 일관된 운영 콘솔 UI로 재구성한다. 레거시 `/admin-legacy`는 범위에서 제외한다.

## 결정 및 제약

- 대상: `admin-frontend/`의 화면단만 변경한다.
- 기존 React Query 훅, API 계약, 권한 분기, 화면 경로와 조치 흐름은 바꾸지 않는다.
- 시각 방향: 중립 배경·짙은 네이비 정보 위계·청록 primary를 사용하는 고밀도 운영 콘솔.
- 레거시 콘솔 진입 링크는 새 화면에서 제거한다.
- 2026-07-21 후속 개편은 `DESIGN-admin.md`를 정본으로 삼아 라이트 사이드바, teal 토큰, 틴트 상태 배지, 공용 KPI 표면을 적용한다.

## 단계

1. 전역 토큰과 앱 셸 재구성 → 검증: 모든 기존 라우트가 동일한 sidebar/header/page header로 렌더된다.
2. 대시보드·로그인 화면 재설계 → 검증: 처리 큐가 우선 노출되고, 기존 KPI/차트/이동 링크가 유지된다.
3. 테이블·상세·폼 표면 통일 → 검증: 기존 목록·상세·CMS 화면의 데이터와 액션이 유지된다.
4. 빌드·린트·시각 확인 → 검증: admin frontend TypeScript 빌드와 ESLint가 통과한다.

## 2026-07-21 후속 적용

- `theme/tokens.ts`에 Ant Design 전역 토큰과 차트 팔레트를 단일화했다.
- 앱 셸을 라이트 사이드바, 64px 탑바, 컨텐츠 페이지 헤더, 하단 관리자 계정 카드 구조로 전환했다.
- 상태 배지를 시맨틱 틴트 pill로 바꾸고 대시보드 KPI를 `StatCard`로 통일했다.
- 기존 API, React Query 훅, 라우트, 권한 분기와 업무 액션은 변경하지 않았다.
- 검증: `docker compose --env-file .env up --build -d admin_frontend` 성공.
- 라이트/다크 테마 토글을 추가하고 `saigon-admin-theme` 로컬 저장값과 OS 선호 테마를 연동했다.
- 제공된 Saigon Rider 로고 원본에서 favicon(64px)과 사이드바 로고(256px) 파생 자산을 생성해 적용했다.
- 공식 랜딩의 사이공 스카이라인 이미지를 로컬 자산으로 포함하고 로그인 화면을 2열 브랜드 히어로·반투명 인증 패널로 재구성했다. 기존 인증 mutation·캐시·라우팅 계약은 유지했다.
- 관리자 탑바와 로그인 화면에서 `https://www.saigon-rider.com/` 공식 랜딩을 새 창으로 열 수 있게 연결했다.

## 추적

- Plane 등록: 권한 오류(403)로 이 세션에서 생성 불가.
- Notion 미러: 외부 SaaS 쓰기 권한 정책으로 이 세션에서 생성 거부됨.
