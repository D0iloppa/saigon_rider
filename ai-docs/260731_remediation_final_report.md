## 3. 되돌린 것 — N-5 (감독 검증 실패 사례)

2단계에서 N-5(위치 SoT)를 "리스트뷰를 전역 store 로 수렴"시켰다. 그런데 [`frontend-page-map.md:128`](./context/frontend-page-map.md) 에 **대표가 2026-07-27 에 내린 결정**이 명문으로 있었다:

> **⚠️ 알려진 갭 (대표 결정: 현행 유지)** … 통합안 3가지를 검토했고 대표가 현행 유지를 택했다 — 이유: 리스트가 스토어에 쓰면 주유소·정비소·날씨·홈의 동네까지 함께 바뀌기 때문(정보 화면 침습, **침수지도 사고와 동일 경로**). … **이 불일치는 인지된 트레이드오프다.**

즉 코드의 "전역 건드리면 회귀" 주석은 워커가 판정한 "사후 추측"이 아니라 **대표 결정의 인코딩**이었다. **감독이 워커의 커밋 히스토리 추론만 검증하고 `frontend-page-map.md` 를 대조하지 않은 것이 원인**이다(CLAUDE.md 는 ADR → page-map 순 확인을 규정하는데, ADR 이 부재해 page-map 확인까지 건너뛰었다). 이미 커밋된 뒤에 발견해 되돌렸고, 같은 파일의 N-2·S-5 변경은 보존했다.

**구조적 원인과 권고**: 대표 결정이 서술형 문서 본문에만 흩어져 있고(한 줄이 수천 자), ADR 은 비어 있다(`no_adr`). **리메디에이션과 별건으로 "대표 결정 사항"을 ADR 로 추출하는 과업을 권고한다** — 하지 않으면 같은 사고가 재발한다.
