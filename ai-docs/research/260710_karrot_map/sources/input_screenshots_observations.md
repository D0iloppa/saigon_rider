# 당근 동네지도 실기기 스크린샷 관찰 노트

## 이미지1 — 동네지도 탭 기본 화면 (지도 브라우징 상태)

### 탭 구조 (Q1)
- 하단 5탭: `홈 / 커뮤니티 / 동네지도 / 채팅(뱃지 22) / 나의 당근`
- **동네지도가 5탭 중 정중앙(3번째)** — 핀 모양 아이콘, 활성 상태
- 진입 첫 화면 = **풀스크린 지도** (리스트가 아님)

### 상단 요소 (Q1)
- 라운드 검색바: placeholder **"집 근처 업체 검색"** + 우측에 프로필 아바타 원형
- 검색바 아래 가로 스크롤 **카테고리 칩**: `🧳 포장주문` `% 할인중` `🍴 음식점` `🚚 용달` (+우측으로 더 있음)
  - 카테고리가 업종(음식점)만이 아니라 **행동/혜택 축(포장주문·할인중)과 서비스 축(용달)이 혼재**

### 지도·핀 (Q2)
- 지도는 자체 스타일(연회색 도로·연녹 공원·연청 수계, 채도 낮음) — 핀·라벨이 도드라지는 배경
- 업체 핀: **주황 원형 + 업종 아이콘(포크/스푼)** + 핀 아래 **주황색 상호명 텍스트 라벨** (스텔라떡볶이, 세나칼국수, 짬뽕타임, 모락로제떡볶이닭강정, 아케이드엑스루프탑바베큐)
- 일부 핀 우상단에 **빨간 점** — 새 소식 있는 업체 표시로 추정 (이미지1의 말풍선과 연동)
- 비즈니스 외 POI도 별도 시각 언어로 노출: 파란 계열 아이콘(오즈마사지 라벨, 채팅 말풍선 마커), 지하철역(오산역), 산 아이콘 등
- **소식 프리뷰 말풍선**이 지도 위에 직접 노출: "새소식 1일 전 — 배달의민족은 기상 악화 등으로 배달이 지연되거나 배차 …" (업체가 쓴 소식 게시글의 첫 줄이 지도에서 바로 보임)
- 이 줌 레벨(도시 일부, 수 km 스팬)에서 상호명 라벨 핀 5~6개 + 보조 POI 수 개 — 과밀하지 않게 선별 노출됨(선별 기준은 화면만으론 불명)

### 좌측 플로팅 버튼 스택 (Q1/Q4)
- 🟠 운동화 아이콘 — 동네걷기(2025-09 PR의 '혜택 미션') 진입으로 추정
- ♡ 하트 — 저장한 장소(2022 PR '장소 저장 기능'과 부합)
- 🏠+ 집에 플러스 — 장소 등록/제안 진입으로 추정
- ⊕ 크로스헤어 — 현위치

### 우하단 (Q1)
- 파란 원형 버튼 **"내 장소"** (집 아이콘)
- **주황 대형 + FAB** (등록 액션 추정)
- 하단에 콘텐츠 카드 상단이 살짝 노출: "떡볶이 생각나는 날엔 당근이죠?" — 접힌 바텀시트/추천 콘텐츠 존재

## 이미지2 — 장소(핀) 선택 상태

### 선택 상호작용 (Q2)
- 선택된 장소는 **대형 주황 물방울 핀**으로 강조 + 상호명 라벨(아케이드엑스 루프탑바베큐), 지도 중앙 배치
- 상단 검색바·카테고리 칩은 그대로 유지
- 우측에 **X(선택 해제)** 버튼
- 하단에 **가로 스와이프 카드 캐러셀** — 좌측 카드 일부(다른 업체 카드: "…오산시청점 일반음식", 쿠팡이츠 이미지 포함)가 보임 → 카드가 1장이 아니라 좌우로 넘기는 구조

### 소셜 프루프 (Q2/Q4)
- 카드 위에 파란 칩 **"👁 10명이 보는중"** — 실시간 열람자 수 노출

### 업체 소식 카드 내용 (Q4 — 참여 루프의 실물 증거)
- 카드 = 업체 아바타 + 상호명 + "3시간 전" + 소식 본문:
  > "안녕하세요~루프탑바베큐입니다. 드디어 달달한녀석님의 **100번째 단골맺기**로 총 100분의 단골고객님을 모시게되었습니다. **7월 한달동안 증정쿠폰을 제시해주시면 선착군 3○분의 단…**"
- → **단골 맺기(누적 카운트) + 쿠폰 증정**이 업체 소식을 통해 지도 표면까지 올라오는 구조가 실물로 확인됨
