# 사이공라이더 실기기 점검표 (간이판)

> 각자 본인 폰에 앱 설치하고, 위에서부터 순서대로. 되면 O, 안 되면 X 치고 맨 아래 칸에 한 줄만 적어주세요.
> 상세 기술 문서는 `saigon_rider_test_cases.md` (개발자용).

## 시작 전

### 사람 3명 + 폰 3대로 역할 나누기

| 사람 | 역할 | 어디를 보나 |
|---|---|---|
| **1번** | 파는 사람 / 손님 | 본인 폰 앱 |
| **2번** | 사는 사람 | 본인 폰 앱 |
| **3번** | 가게 사장님 | 본인 폰 앱 |
| (아무나) | 관리자 | **노트북 브라우저** — `https://saigon.doil.me/admin/` (ID/비번 별도 전달) |

혼자 하셔도 됩니다. 폰 2대만 있으면 1번·2번 역할을 번갈아 하시면 됩니다.

### 각자 폰에서 로그인 (처음 1회, 3분)

| # | 이렇게 한다 | 이렇게 나와야 한다 | O/X |
|---|---|---|---|
| A | 앱 실행 | 로그인 화면에 **Zalo / Google / Apple** 버튼 | |
| B | 본인 계정으로 로그인 | 성공, 처음이면 프로필 설정 화면으로 | |
| C | 닉네임·사진 넣고 완료 | 홈 화면 진입 | |

**세 사람 모두 서로 다른 계정이어야 합니다.** 각자 자기 폰, 자기 Zalo/Google 계정 쓰면 자동으로 갈립니다.

*※ 폰 번호 인증은 지금 하지 마세요.* 중고거래 3장에서 **일부러 미인증 상태로 시작**해 차단이 걸리는지부터 봅니다.

## ※ 이건 원래 안 되는 겁니다 (버그 아님)

테스트 중에 만나도 X 치지 마세요. 아직 안 만든 기능입니다.

1. 단골 맺은 가게가 소식을 올려도 **알림이 안 옵니다** (단골 목록을 직접 열어야 보임)
2. 가격표 항목 **수정 불가** — 삭제 후 재등록
3. 침수 지도의 **집계 배지는 눌러도 반응 없음** (개별 마커만 눌림)
4. 업체 대시보드에 **단골 손님 명단 화면 없음** (숫자만 나옴)
5. 광고는 지금 **꺼져 있어서** 앱 어디에도 광고가 안 보입니다 (대시보드 통계는 별개로 정상)
6. 물건 상태를 손으로 **"판매완료"로 못 바꿉니다** — 약속 완료를 눌러야 자동으로 바뀝니다
7. 매너온도 **숫자는 화면에 안 나옵니다** — 등급 칩만
8. **인증 문자가 실제로 오지 않습니다** — 아무 6자리나 넣으면 통과 (개발 서버 설정)
