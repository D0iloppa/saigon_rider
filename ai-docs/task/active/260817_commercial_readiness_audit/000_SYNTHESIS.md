## 1. 한 장 요약

**거래는 돌아간다. 그 위에 얹혀야 할 시스템 층이 비어 있다.**

구매자·판매자의 핵심 루프(등록 → 탐색 → 문의 → 가격협상 → 약속 → 완료 → 후기 → 평판)는 4관점 감사 결과 **코드상 전 구간이 이어져 있다.** 2026-08-12 이후 5개 커밋이 남아 있던 P0급 진입 장벽(익명 열람·채팅 탭·구매자 완료 요청권·위치 게이트·첫 화면 분기)을 실제로 닫았고, 기존 감사 문서들이 "미해결"로 적어둔 항목 중 상당수가 이미 해결됐다.

비어 있는 것은 **거래를 둘러싼 시스템 층 세 가지**다:

| 층 | 상태 | 결과 |
|---|---|---|
| **신뢰(Trust)** — 진위 검증·적정가·신고 처리 정책 | 도구는 있고 **판단 규칙이 0** | 사기·쓰레기 매물을 막을 자동 게이트가 없고, 제재는 100% 운영자 재량 |
| **수익(Revenue)** — 광고 노출·측정·리포팅 | 위아래는 있고 **가운데가 끊김** | 광고를 팔 수는 있으나 효과를 증명할 수 없어 재구매가 불가능 |
| **계측(Measurement)** — 퍼널·GMV | **전무** | 무엇이 되고 안 되는지 판정할 수단 자체가 없음 |

**대표가 추가로 지목한 6건(진위 검증·적정가·신고 처리·광고 노출·광고 리포트·광고 측정)은 이 세 층과 정확히 일치한다.** 감사가 독립적으로 같은 결론에 도달했다.

**공개 가부**: 파일럿(한 개 구 한정) GO 가능. **전면 상용 공개는 NO-GO** — 차단 사유는 아래 §5 P0.

### 2-1. 구조적 사실 3가지

1. **수익은 업체 광고 단일 의존.** C2C 수수료·정산 경로가 코드에 아예 없다(`grep commission|정산|settlement|payout` 무결과 — W2 S-10). Payment/Invoice/Settlement 모델도 스키마에 부재(W4 E-4). 즉 **광고 수익 경로가 끊기면 매출은 0이다.**
2. **매물은 사전 승인 없이 즉시 노출된다**(`market.py:655` → `status="ON_SALE"`). 공급 축적에는 유리하지만, **진위 검증이 0인 상태에서의 무마찰 등록은 사기꾼에게도 무마찰**이다.
3. **어드민 의존 방향이 뒤집혔다.** T&S 코어(신고·매물 모더레이션·거래 이의·CMS·감사로그)가 신규 SPA 전용이고 legacy 에 없다 → `admin_frontend` 컨테이너가 **T&S 단일 장애점**(W4 §2).

### ④ 광고 노출

**현황: 로직은 완성돼 있고, 스위치가 꺼져 있다.**

- **선택 로직**: 결정적 **smooth weighted round-robin**(`ad_exposure.py:18`). `weight = tier.exposure_weight × ad_fee` 이나 `ad_fee` 가 전 행 1로 정규화돼 사실상 **티어 가중치만** 작동. **경매·입찰 개념 없음** — 게이트(`ad_gating.py:26-50`)를 통과한 광고는 **전부 시퀀스에 포함**되고 빈도만 다르다. "낙찰"이 아니라 "다 보여주되 비율 조정".
- **인벤토리**: 슬롯 부족으로 밀려나는 광고가 없다. 지면이 무한하다고 가정한 모델 — 광고주가 늘면 개별 노출 지분이 희석되는데 이를 광고주에게 알릴 수단이 없다.
- **빈도 제한**: 일반 광고 **없음**. 근접광고만 있음(`cooldown_hours=24`, `daily_notify_cap=2`, `init/174`).
- **타겟팅**: `district_id`(지역) 하나뿐. 카테고리·시간대·사용자 속성 타겟팅 0.
- **킬스위치 현황**: `ADS_ENABLED = false`(`adPlacement.ts:18`, 대표 지시 2026-07-25) → **주 노출면 4종(마켓 피드·마켓 상단·홈 카드·홈 빈상태) 전부 OFF.** 근접광고도 `proximity_policy.is_enabled=FALSE`. 현재 광고가 보이는 곳은 광고 상세 직접 URL·공개 업체 프로필 2곳뿐 = **발견 유입 경로 없음.**
- **주의**: 이 킬스위치는 **소스 코드 상수**다. 런타임 feature flag 가 아니라서 **켜려면 프론트 재빌드·재배포가 필요**하다(W4 I-6).
