## 2. 조정 필요 (4건)

### 조정① — UrBox 발송일: 7/18(토) → 7/20(월)
위 캘린더 오류의 직접 수정. 히엔 선생님 감수는 7/17(금)~주말 중 여유 있게.

### 조정② — 광고 계정 생성을 "7월말"에서 **7/21(화)로 선행**
신규 메타(페북/인스타) 광고 계정은 **초기 지출 한도·계정 검증(비즈니스 인증) 이슈**가 잦다 — 계정 생성·결제수단 등록·비즈니스 인증만 다음주 초에 미리 해두고, 픽셀/타겟/소재는 예정대로 7월말. 계정 문제가 오픈 직전에 터지는 걸 막는 무비용 보험.

### 조정③ — 쇼츠에 "기획 합의" 단계 추가 (7/22 수)
현 계획은 촬영·편집·공개일만 있고 **무엇을 찍을지가 없다.** 첫 영상 제작은 늘 기획에서 밀린다. 7/22(수)에 대표님과 15분이라도: 콘셉트(앱 데모 vs 라이더 일상 vs 쿠폰 이벤트 티징), 채널(유튜브 쇼츠/틱톡/릴스 — 결정 2번과 묶임), 언어(vi 자막 여부 — 히엔 검수 연계). 이게 정해져야 7월말 촬영이 실제로 굴러간다.

### 조정④ — NDA 준비 주체에 기본값 제안
대표 결정 4번이 지연되면 NDA 트랙 전체가 선다. **"응답 없으면 UrBox에 초안 요청"을 기본값으로 명시**하길 권함 — UrBox가 "NDA 필요"를 먼저 말했으므로 초안 요청은 자연스럽고 우리 작성 비용도 없다. (대표님껜 "이의 없으시면 그쪽 초안 요청으로 진행하겠습니다" 형태)

## 4. 유지 판정 (잘 된 것)

- **8/14 버퍼형 확정** — 폐쇄테스트 완료로 당길 수 있음에도 리스크 흡수를 택한 것: 3인 팀 + 첫 출시엔 옳은 판단.
- **시범(7/24)과 제출(7/29) 사이 영업일 3일** — 짧아 보이나 제출본엔 치명결함 수정만 담고 심사 중 시범을 계속 돌려 8/14 게시 전 업데이트하면 됨. 타당.
- **쿠폰 트랙 분리 + 성사 시 오픈 이벤트 활용** — 외부 종속을 오픈일에서 끊으면서 업사이드만 취하는 구조. 유지.
- **go/no-go 3기준(심사·결함·소재)** — 적절. Google '관리형 게시'/Apple '수동 출시'로 심사 통과분을 8/14까지 홀드하는 것도 정석.
- **대표 결정 5건 분리** — 의사결정 병목을 명시화한 것 좋음. (조정④의 기본값만 보강)
