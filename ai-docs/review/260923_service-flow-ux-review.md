### 1. 검토 기준 (Karrot lens) + 커버리지

#### 1-1. 판정 기준 8개
1. **신뢰는 동네·거래 기록으로 증명한다.** 판단 순간(매물 상세 판매자 블록, DM 헤더, 프로필)에 매너온도급 신뢰 지표(신뢰 티어·거래 후기·인증)가 보여야 하고, 그 자리에 게임 지표(Lv·EXP·RP)는 0개.
2. **화면당 주행동 하나, 나머지는 점진 노출.** 채움 버튼은 화면(또는 카드)당 하나. 헤더 아이콘 상한 3개([뒤로][맥락 1][더보기]).
3. **거래는 채팅 안에서 끝난다.** 가격제안·약속·송금·완료·후기가 타임라인 **카드**로 흐르고, 상단 고정 맥락은 **매물 카드 1장**이 상태를 흡수한다(배너 적층 금지).
4. **안전 개입은 사고 직전에.** 선입금 요구·외부 링크 같은 사기 패턴 직전 경고, 신고·차단은 어디서든 2탭 이내. 되돌릴 수 없는 행동 = 위험 톤 + 확인 1회(버튼은 행위명 "탈퇴"·"차단"), 되돌릴 수 있는 행동 = 확인 없이 + 실행취소.
5. **로그인 게이트는 가치 경험 뒤에.** 탐색(홈·마켓·지도·피드 열람)은 열고, 쓰기·개인화·상대에게 영향 가는 행동에만 게이트.
6. **빈 상태 ≠ 실패 상태.** 둘을 반드시 구분하고, 빈 상태에는 다음 행동 CTA 1개. 실패를 빈 목록/기본값으로 위장 금지.
7. **카피는 짧고 친근하게("~해요"), 한 손 조작.** 주행동은 하단, 파괴적 행동은 끝에. 떠 있는 요소 0.
8. **베트남 컨텍스트.** Zalo 로그인, 현금·은행이체(QR은 현금 대체이지 결제 검증 아님), 오토바이 이동 중 손이 바쁨, vi 기본·ko/en 병행.

### 4. 크로스플로우 이슈 (여러 프레임에 걸친 불일치)

#### X-1. 로그인 게이트 정책이 화면마다 다르다 — 라우트 실측 근거
`App.tsx` 실측: public = `/market`, `/market/:id`, `/market/search`, `/map`, `/map/search`, `/biz/:id`, `/settings/terms|privacy` / **PrivateRoute = `/home`, `/feed`, `/feed/post/:id`, `/profile/:userId`, `/dm`, 그 외 전부.**
- 마켓·지도·업체는 비로그인 열람 가능인데 **홈·커뮤니티 피드·타인 프로필은 로그인 필수** — 비로그인 사용자가 탭바 6개 중 2개(홈·커뮤니티)를 누르면 벽. 특히 매물 상세(public)에서 판매자 블록 탭 → 프로필(private) → 로그인 벽: "이 사람 믿어도 되나"를 확인하려는 순간에 게이트가 걸림.
- `/map/search`는 public인데 진입 아이콘이 `requireAuth`(F-MP-01 FR-1) — 라우트와 UI 게이트가 어긋남.
- **권고(당근 원칙 "가치 경험 후 로그인")**: 열람 전부 open — 홈·피드 열람·타인 프로필·업체 상세·지도 검색. 게이트는 쓰기(글·매물·댓글·응원)·개인화(찜·팔로우·알림)·상대 영향(채팅·제안·약속·신고·차단)에만. 게이트 화면은 F-S0-01 FR-2 문법(막힌 이유 + 해결 CTA 같은 자리) 1종으로 통일. → 서비스플로우 신규정의 **Y** (비로그인 홈/피드 상태 정의 필요, F-H-01 FR-1 `if(!user) return null` 해소).

#### X-2. 신뢰 신호가 판단 순간에 없고 프로필 깊숙이 있다

- **권고**: 신뢰 티어 칩을 "닉네임 옆 상시 동반 요소"로 규칙화(닉네임이 보이는 곳 = 칩이 보이는 곳). 게임 지표는 스토리보드 전 프레임에서 일괄 제거(B3 OUT의 "일괄 삭제"와 별개로 **와이어 정정**은 지금 가능).

#### X-3. 상단 맥락 층이 프레임마다 2~3층
