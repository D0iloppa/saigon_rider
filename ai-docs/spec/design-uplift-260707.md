# 디자인 업리프트 1차 — 마켓 표면 (2026-07-07)

> 방식: Sonnet 리서치(당근 공식 Seed Design·티어다운·Chotot 라이브 실측·Mercari A/B 사례·NN/g) → Fable 디자인 패스. 리서치 전문은 세션 산출물, 실행 결론만 여기 요약.
> 커밋: 플랫 리스트·가격 표기·홈/상세 다듬기 (before/after: `tools/qm/shots/up-market.png` → `final-market.png`)

## 적용 (1차)

| 항목 | 내용 | 근거 |
|---|---|---|
| **마켓 플랫 리스트** | ListingCard 박스(테두리·그림자·라운드) → 헤어라인 구분선 행. 썸네일 84→104px/r10, 제목 400·가격 800 위계, active는 배경 틴트. 마켓/검색/찜/동네지도 4화면 동시 적용 (컨테이너 gap 0, AdCard·feedCard는 개별 마진, 지도 selected는 브랜드 틴트+링) | 당근 실증 위계(가격→제목→위치·시간→카운트), NN/g "고정 위치 리스트가 스캔·비교에 유리" |
| **가격 표기 현지화** | `₫3.220.000` → **`3.220.000 đ`** (마침표 천단위 + đ 후치, 공백) — `formatPriceVnd` 단일 수정으로 전 화면 반영 | Chotot 라이브 실측 표준 표기. 축약형(15tr, 500k)은 구조화 필드에 쓰지 않는 것도 확인 — 현행 유지 |
| **오렌지 절제** | 가격내림 배지 solid 오렌지 → brand-50 배경+brand-600 텍스트 (리스트·상세 통일). 홈 안전거래 배너 27px/900 → 20px/800·연한 그라데이션 | 당근 리브랜딩: "오렌지 과용 폐기, 포인트로만" (공식 블로그) |
| **가짜 데이터 제거** | 홈 인기상품 카드의 하드코딩 `♥0` 제거 (데이터 소스에 카운트 없음) | 다크패턴/신뢰 원칙 — 가짜 수치는 신뢰 손상 |

인풋 필드의 `₫` 접두(가격 입력 시트 3곳)는 입력 UX 관례상 유지 — 표시와 입력의 의도적 비대칭.

## 알려진 소소한 관찰 (보류)

- 홈 가로 카드(92px)에서 8자리 이상 가격(`24.500.000 đ`)이 2줄로 줄바꿈 — 카드 폭 확대 또는 고가 축약 검토.
- info 페이지들의 `N₫` 표기(주유가 등)는 이번 범위 밖 — 후속 통일 대상.

## 리서치가 제안하는 제품 차원 후속 (구현 안 함 — 결정 필요)

1. ~~매너온도 은유 재검토~~ → **결정·구현 완료 (2026-07-07)**: 온도 은유를 노출하지 않는 **5단계 신뢰 티어**(주의 필요→새 이웃→좋은 이웃→믿음직한 이웃→최고의 이웃, 3로케일)로 전환. `lib/trustTier.ts` 매핑 + `TrustTierChip` — 매물상세 판매자 신뢰행(분해형 배지 선두)·프로필 노출. 조사 결과 온도는 화면 렌더가 원래 0곳(죽은 배관)이라 "표시 교체"가 아닌 신규 도입이었음. 내부 스칼라 계산은 유지(표현 계층만 전환), °C 포맷터·orphan i18n 제거. ProfileCard 는 API 에 필드가 없어 후속.
2. **거리 표기 업그레이드** — 동네명만이 아니라 "오토바이 N분" 이동시간 환산 (번개장터 패턴, 오토바이 도시 호치민 최적).
3. **연락 채널** — Chotot는 전화/SMS/채팅 3중 CTA이고 전화 응답률이 더 높다고 자체 안내. 채팅 단일 CTA 재고 여지.
4. **등록 CTA** — 당근·번개장터 모두 탭바 상시 "등록" 탭 (우리는 FAB). 중고거래 중심 피벗이면 탭바 재구성 시 함께 검토.
5. Chotot 배지 관례 — "N đã bán"(판매 카운터), "Còn bảo hành"(보증중) 등 소셜프루프형 배지.
