## 4. 출시 HOLD 게이트 (진짜 블로커 — 시범 착수 전 필수)

코드로 못 닫는 것. **이 4종이 닫히기 전에는 시범(실사용자) 착수 불가.**

1. **실기기(Android/iOS)** — 권한 프롬프트·백그라운드 GPS·FCM 푸시·OAuth 딥링크 왕복. **Mac Capacitor 빌드 대기 중**(`native/CAPACITOR_MIGRATION.md`)이 최대 병목.
2. **외부 API 키** — Google Routes(SGR-269 코드 완료·휴면), OpenWeather(설정됨), **Google Translate 403(재발급 필요)**. 키 없으면 지도/번역이 폴백으로만 동작.
3. **Docker fresh-volume 부트스트랩** — 기존 dev 볼륨엔 마이그레이션 `139/140/145/146` 수동 backfill 필요. 운영은 fresh volume로 자동 적용되나 **1회 검증 필수**.
4. **약관·개인정보(vi) + 법무** — 개인정보처리방침 vi 게시, 가입 약관 동의 버전, 탈퇴/내보내기 보존범위. **제품·법무 결정 대기**.
