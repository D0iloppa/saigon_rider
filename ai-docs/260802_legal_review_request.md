# 법무 검토 요청서 — 개인정보처리방침·이용약관 초안 (2026-08-02)

**요청 배경**: 출시 게이트 4 차단 항목. 앱 내 공표 문안(개인정보처리방침·이용약관)과 실제 시스템 동작 사이의 불일치를 전수 대조하여, **실제 동작에 맞춘 초안**으로 수정했습니다. 본 문서는 그 대조 결과와 수정 초안의 근거이며, **최종 문안 확정은 법무 검토·승인 사항**입니다. **2026-08-02 갱신 — 화면 노출 표식 제거**: 초안 표식(`[법무 검토 전 초안]` 등)과 빈칸 표시
(`[법무 확인 필요: 보존 근거 법령·조문과 보존 기간]`)가 **개인정보처리방침·이용약관 본문 안에 있어
사용자에게 그대로 노출**되고 있었다. 대표 승인(2026-08-02)에 따라 세 로케일에서 전부 제거했다.

- 표식 제거는 **법무 검토가 끝났다는 뜻이 아니다.** 외부 법률 자문은 여전히 받지 않았다 —
  그 사실을 사용자 화면이 아니라 **이 문서에** 남긴다.
- P-3 의 보존 근거 조문·기간 빈칸은 **문장에서 괄호만 걷어냈다**(근거를 지어내지 않았다).

  법무가 조문·기간을 확정하면 그 문장에 끼워 넣으면 되며, **코드 변경 없이 문안만 바꾸면 된다.**

**문안 위치**: `frontend/src/locales/{ko,en,vi}/translation.json` 의 `legal.privacyHtml` / `legal.termsHtml` (ko 원본 기준으로 en·vi 동등 반영, 세 로케일 의미 동일 확인). 시행일 표기는 기존 그대로 2026-06-01 유지 — 개정 시행일·개정 고지 방식은 법무 결정 사항(하단 질문 Q1).

## 3. 코드-문안 대조 중 발견했으나 문안으로 해소되지 않는 사항 (엔지니어링/법무 공동 확인 필요)

문안은 실제 동작 기준으로 작성했으므로 아래는 초안에 반영하지 않았고, 별도 조치가 필요합니다.

1. **Engine 측 데이터 파기 부재**: 탈퇴·30일 파기 배치는 BFF DB 만 다룬다. Engine DB 의 기기 UUID·FCM 토큰 매핑(`engine/alembic/versions/029_device_user_map_fcm_token.py`)과 RP 지갑·미션 기록은 탈퇴 후에도 삭제 경로가 없다 (`delete_account` 는 `engine_client.delete_device_map` 을 호출하지 않음 — `backend/app/routers/users.py:248-313`, 클라이언트 메서드는 존재: `backend/app/engine_client.py:527`). 방침 §4 열거에 포함하지 않았으나, **기기 정보가 사실상 무기한 잔존** — 파기 배치 확장 또는 방침 추가 서술 중 택일 필요.
2. **이미지 원본 파기 부재**: 파기 배치는 DB 행만 삭제하고 `contents` 행·imgproxy 볼륨의 이미지 파일(아바타, 삭제된 피드글 첨부 등)은 삭제하지 않는다 (`purge_deleted_accounts.py` `_OWN_DATA_TABLES` 에 contents 부재).
3. **문의처 이메일 정정(2026-08-02 조치)**: 문안의 `support@sgr.com` 은 도메인 자체가 틀렸다(실제는 saigon-rider.com). ko/en/vi 세 로케일 전체를 **`support@saigon-rider.com`** 으로 교체했다(로케일 내 `sgr.com` 잔존 0건). ⚠️ **그 메일함이 실제로 존재하는지는 확인 불가** — 미생성 상태로 출시하면 공표된 개인정보 문의처가 불통이 된다. **대표 확인 항목.**
4. **연령 요건(만 14세)**: 약관에 있으나 가입 시 연령 확인 로직은 없음(체크박스 동의만 — `database/init/163_user_consent_capture.sql`). 베트남 현지법상 연령 확인 의무 여부 확인 필요.
