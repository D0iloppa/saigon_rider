## 0. 이 미팅에서 내가 하려는 것 (한 줄)

## 1. Zalo 연동 — ⚠️ 용어부터 정리 필요 (가장 먼저 확정)

대표가 말한 "잘로랑 쿠폰 연동"이 아래 **둘 중 무엇인지** 미팅 서두에 반드시 확인한다. 우리 코드 상태가 서로 다르다.

| 구분 | 무엇 | 현재 코드 상태 | 블로커 |
|---|---|---|---|
| **(A) Zalo 로그인** | 소셜 로그인 provider로 Zalo 추가 | **구현 완료** (백엔드 PKCE 토큰교환 `oauth.py`, 프론트 로그인 버튼, DB 스키마 provider='zalo') | **Zalo 앱 승인 대기** → `zalo_app_id`/`zalo_app_secret` 미발급이라 실동작 불가 |
| **(B) Zalo 쿠폰 연동** | Zalo를 통한 쿠폰/바우처 발급·배포 | **미착수** (앱 내 쿠폰 기능 자체가 없음) | 요구사항·채널 미정 |

### 확인/결정해야 할 것
- **(A) 로그인**: 개발자 계정 승인이 **언제 나오는지**, 승인 조건(사업자등록·앱 심사자료·개인정보처리방침 URL 등)이 무엇인지. → 이게 **베트남 로그인의 사실상 유일한 블로커**. 승인만 나면 자격증명 입력 후 즉시 붙는다.
- **(B) 쿠폰**: "쿠폰 연동"이 정확히 무엇을 의미하는지 파트너/대표와 정의부터. 후보 채널:
  - **Zalo OA(Official Account) 바우처** — 공식 계정에서 쿠폰 브로드캐스트/발급
  - **ZNS(Zalo Notification Service)** — 템플릿 메시지(OTP·주문알림형), **건당 유료**
  - **앱 내 쿠폰 + Zalo 로그인 유저 대상 지급** — (A)에 종속
  - → 어느 방향이냐에 따라 개발 범위·비용·일정이 완전히 달라짐. **오늘은 "방향 결정"까지만** 받아오면 충분.

## 2. 출시 (Launch)

### 확인해야 할 것
- **출시 정의**: 웹앱(PWA) 출시인가, 스토어(Google Play / App Store) 출시인가? — 우리 최근 작업은 **웹앱 우선**. 네이티브 빌드는 Mac 측 검증 대기 상태.
- **출시 필수 선행 조건**(현지 파트너가 처리해야 함):
  - Zalo 로그인 승인 (§1-A) — 베트남 유저 로그인 수단
  - 스토어 출시 시: **현지 사업자/개발자 계정**(Google Play·Apple), 앱 심사용 자료
  - **개인정보처리방침·이용약관**(베트남어) URL — Zalo/스토어 심사 공통 요구
  - 도메인/상호 등 현지 법인·명의 확인
- **콘텐츠 현지화 검수**: 카피·베트남어 번역·현지 관례(가격표기 `N đ` 등)는 코드상 반영됨 → **현지인 실검수** 필요.

### 내가 정리해 갈 것
- 출시 전 **체크리스트**(무엇이 코드 완료 / 무엇이 외부 대기)를 표로 제시 → 파트너에게 "당신 몫"을 명확히 넘긴다.
- 현실적 출시 시나리오: **1차 웹앱 소프트런치 → Zalo 승인 후 로그인 정식화 → 스토어**의 단계안을 제안.

## 3. 광고 (Advertising)

### 확인/협의할 것
- **채널**: Zalo Ads / Facebook·Instagram / TikTok VN / 오프라인(현지 드라이버·거래 커뮤니티) 중 무엇을 우선?
- **타깃**: 초기 타깃 지역(HCMC 우선)·유저층(오토바이 이용자·중고거래) 정의.
- **집행 주체**: 광고 운영을 현지 파트너가 직접 하나, 대행/공동인가? → **비용(§4)과 직결**.
- **콜드스타트**: 마켓(중고거래) 피벗 상태라 초기 매물·유저 확보 전략 필요. (관련: `ai-docs/spec/marketplace-cold-start-strategy-final.md`)
- **측정**: 광고 성과 추적 지표·설치/가입 트래킹을 붙일지(개발 필요 여부).

## 4. 비용 협의 (Cost)

미팅 전 **항목을 미리 나눠** 가서, "무엇에 대한 비용인지" 흐릿하지 않게 한다.

| 비용 항목 | 성격 | 확인 포인트 |
|---|---|---|
| 현지 파트너 활동비/수수료 | 인건·운영 | 월정액 / 성과 / 지분 중 무엇 |
| Zalo 관련 | ZNS 건당 과금·OA 운영비 등 | §1-B 방향 결정 후에나 산정 가능 |
| 광고 집행비 | 마케팅 | 초기 예산 규모·집행 주체 |
| 스토어/계정/법인 | 출시 인프라 | Apple 연 $99·법인/명의 비용 등 |
| 서버/인프라 | 운영 | 현 Docker 4서비스 단일 서버 — 트래픽 증가 시 증설 시점 |

- **오늘 목표**: 전체 확정이 아니라 **비용 항목의 구조 합의 + 1차 예산 규모**만. 세부는 방향(§1-B, §3) 확정 후.
