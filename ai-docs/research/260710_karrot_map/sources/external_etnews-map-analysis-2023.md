## 원문 발췌 (raw)

당근마켓이 자체 지도 서비스인 '당근지도'의 데이터를 분석해 한국인이 선호하는 음식별 맛집 밀집 지역을 공개했다.

### 맛집 순위 분석 (당근지도 데이터 기반)
- 떡볶이: 서울 관악구 봉천동(1위), 신림동(2위), 경기 안양시 동안구 안양동(3위)
- 순대: 서울 관악구 신림동(1위), 인천 부평구 부평동(2위), 인천 미추홀구 주안동(3위)
- 족발: 서울 관악구 신림동(1위), 강북구 미아동(2위), 부산 연제구 연산동(3위)
- 국밥: 대구 남구 대명동(1위), 부산 연제구 연산동(2위), 울산 남구 신정동(3위)

### 당근지도 개요

당근지도는 "지역을 인증한 이웃이라면 누구나 직접 자신이 추천하고 싶은 동네 가게와 맛집 정보를 등록하고 이용 후기도 남길 수 있는" 오픈맵 형태의 서비스로, 2021년 11월 정식 오픈했다.
