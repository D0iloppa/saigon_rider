## 동네생활 → 동네지도 장소 자동 연결 관련 원문 인용 (부분)

"LLM이 동네생활 게시글을 읽고 장소 이름으로 보이는 것을 자동으로 찾을 수 있어요."

"해당 장소 이름이 실제로 존재하는 장소인 경우 자동으로 연결을 만들고 '언급된 장소'라는 영역으로 보여주고 있어요."

## 태그 추천 기능 관련 원문 인용 (부분)

"게시글에 사용자가 별도의 해시태그를 사용하지 않은 경우 LLM이 생성해 준 추천 해시태그를 만들고 '추천 태그' 영역에 노출해요."

"이를 통해 더 많은 게시글들이 해시태그를 가지게 되고 풍성한 해시태그 탐색 경험을 제공하게 돼요."
