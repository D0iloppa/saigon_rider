## 진단

`components/ProfileCard.tsx`(713줄, 바텀시트)가 한 표면에 **3층**을 쌓고 있다.

```
바텀시트 (1층)  프로필 헤더 + 팔로우/DM/신고
 └ 피드 리스트 (2층)  ← 페이지네이션(feedPageRef/feedHasMore) 있음
    └ 댓글 오버레이 (3층)  ← activePost
```

**구조적 결함 3가지**
1. **제스처 충돌** — 시트 드래그(닫기) vs 리스트 스크롤. 최상단에서 아래로 당기면 의도가 애매하다.
2. **뒤로가기 의미 부재** — 시트는 URL 이 없다. 댓글까지 열고 뒤로가면 무엇이 닫히는지 예측 불가하고 링크 공유·복귀도 불가.
3. **신호 모순** — 페이지네이션은 "계속 이어짐", 시트는 "곧 닫을 임시 표면". 반대 신호가 겹친다.

**핵심 판정**: 시트를 쓴 게 잘못이 아니라 **시트 안에 페이지네이션 리스트를 넣은 것**이 잘못이다.

## 업계 표준

> **시트는 잎(leaf), 페이지는 탐색(browse).** 끝이 정해진 짧은 것 = 시트, 계속 이어지는 목록 = 페이지.

| 앱 | 남의 프로필 | 게시물 목록 | 시트 용도 |
|---|---|---|---|
| **인스타그램** | 전체 페이지(push) | 프로필 안 3열 그리드 | **댓글**·공유·액션 |
| Threads | 전체 페이지 + 탭 | 단일 컬럼 | 댓글·액션 |
| TikTok | 전체 페이지 | 그리드 | 댓글·공유 |
| 당근 | 전체 페이지 | 판매물품/후기 탭 | 필터·액션 |
| Discord | 유저 팝오버(시트) | **없음** | 액션만 |

인스타그램에는 미니 프로필 시트가 없다 — 아바타 탭이 곧 페이지 push 다. 그리드 탭 → 게시물 페이지, **댓글은 그 위에 시트**. 즉 현행과 층 순서가 정반대(인스타=페이지 위 시트 / 현행=시트 안 페이지). 시트로 프로필을 보여주는 Discord 조차 팝오버 안에 리스트를 넣지 않는다.

## 제약사항

1. **기능 퇴행 금지** — `ProfileCard` 가 가진 것을 빠뜨리지 말 것: 프로필 조회 / 팔로우 토글 / DM 시작 / 신고(사유 시트) / 유저 피드 페이지네이션 / 응원 토글.
2. **댓글은 페이지로 이관** — 목록에서 댓글을 열지 않는다. `FeedList` 의 기존 관례와 동일하게 **응원은 목록에서 O, 댓글은 상세에서만**(page-map §커뮤니티 2026-07-25 기록).
3. **백엔드 변경 0** — `fetchUserProfile` / `fetchMyFeed(userId, page, size)` 가 이미 있다. 신규 API 금지.
4. **내 프로필과 혼용 금지** — 내 userId 면 `/profile`(ProfileMain)로 보낸다. 기존 분기 유지.
5. **i18n 3로케일**(vi/ko/en) 필수. 신규 문구는 최소화하고 기존 키를 먼저 찾을 것.
6. **`<AppImage>` 사용**(`<img>` 금지), 아이콘은 lucide.
