# 출시 준비 현황 브리핑

2026-09-18

중고거래 핵심 기능은 완성도 88%, 보안 취약점 0건으로 개발은 사실상 끝났다.
출시를 막는 것은 기능 부족이 아니라 **실기기 검증 기록 0건 · 장애 감지 수단 부재 · 법률 자문 미착수** 셋이다.

---

## 왜 지금 못 내보내는가

기능은 다 만들었다. 못 나가는 사유는 세 가지다.

| # | 사유 | 구체적으로 | 위험 |
|---|---|---|---|
| 1 | **동작 검증 기록 0건** | 점검 항목 89개 전부 미실행. 실기기 테스트 기록 없음 | 사고를 사용자가 먼저 알게 된다 |
| 2 | **장애 감지 수단 부재** | 서버가 죽어도 알림이 없다. 특히 Zalo 로그인 우회 서버는 단일 장애점인데 무감시 | 로그인 전면 차단을 몰라서 방치 |
| 3 | **법률 자문 미착수** | 외부 변호사 자문을 **아직 받지 않았다** | 공표한 방침과 실제 동작이 다르면 규제 리스크 |

### 3번 — 법률은 개인정보만이 아니다

검토가 끝난 영역은 **없다.** 외부 자문 자체를 아직 받지 않았다.

- **개인정보·약관** — 문안 초안은 끝. 공표 문안이 실제 동작과 15곳 어긋나 고쳤으나,
  **보존 근거 조문이 공란**(베트남 PDPD 13/2023 판단 필요)
- **위치정보** — 근접광고가 사용자 좌표를 서버에 영속 저장한다. 위치정보사업 신고 의무 여부 미검토
- **국외이전** — 서버가 한국에 있다. 베트남 이용자 데이터 이전 고지 요건 미검토
- **전자상거래 신고 · 중개자 책임 · 판매금지품목** — **검토 기록 자체가 없다.**
  중고 오토바이는 도난차량·불법개조 분쟁 소지가 있다

즉 **변호사 회신을 기다리는 상황이 아니다. 선임을 안 했기 때문에 시계가 아예 시작되지 않았다.**

## 언제 나갈 수 있는가

전체 조치 43건 중 **38건은 내부에서 통제 가능**하다. 출시일을 실제로 정하는 것은 밖에서 기다려야 하는 5건이다.

| 구분 | 내용 | 소요 |
|---|---|---|
| 내부 작업 | 실기기 검증, 장애 알림·모니터 구축, 백업 확인, 코드 수정 15파일 | **2~3주** |
| 법률 자문 | 변호사 선임 → 검토 → 문안 반영(반나절 이하) | **선임 시점부터 기산** |
| 스토어 | 서명 빌드 → 심사 | 보통 1~2주 |
| 토스페이먼츠 | 가입 승인 | **출시를 안 막고 매출 개시일만 좌우** |

**결론: "법률 자문 착수 + 2~3주".**
내부 작업과 법률 검토를 동시에 돌리면 변호사 회신이 곧 출시 가능 시점이 된다.
반대로 선임을 미루면 그만큼 그대로 밀린다.

## 오늘 필요한 결정

| # | 결정 사항 | 배경 | 권고 |
|---|---|---|---|
| 1 | **변호사 선임** — 개인정보만이 아니라 위치정보·국외이전·전자상거래까지 한 번에 | 출시일을 결정하는 유일한 변수 | 즉시 착수 |
| 2 | **거래 분쟁 처리 방식** | 지금은 구매자가 "송금했어요"를 누르면 양측도 운영자도 되돌릴 수 없다 | 운영자 되돌림 권한 부여 |
| 3 | **만남 전 송금을 막을 것인가** | 앱 가이드는 "물건 확인 후 결제"인데, 앱 흐름은 송금을 먼저 유도한다 — 자기모순 | 약속시각 전 송금 차단 |
| 4 | **광고 가격표(KRW)** | 가격이 비어 있어 결제 버튼이 계속 숨겨진다 | 6개 값 확정 |
